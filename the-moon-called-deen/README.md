# The Moon Called Deen 🌙

A personal, trilingual static website made by Jushi for Deeeeeeeeeeeen.

## What's included
- English, Tamil and Tanglish language switch
- Animated moon / star styling and opening letter
- Quran reminder section
- Personal poem and motivational letter
- Gym jokes, random smile button and photo scrapbook
- Responsive mobile layout
- Optional background music control

## Preview locally
Open `index.html` in a browser.

## Add background music
The site intentionally does not bundle copyrighted music. Add a royalty-free instrumental MP3 named:
`assets/soft-instrumental.mp3`

Then the music button will play/pause it. On mobile, browsers require the visitor to tap the button before audio starts.

## Publish with GitHub Pages
1. Create a new **public** GitHub repository, for example `the-moon-called-deen`.
2. Upload the contents of this folder (the `index.html`, `style.css`, `script.js`, `README.md` and `assets` folder) to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then Save.
6. Wait for GitHub Pages to publish. Your URL will look like:
   `https://YOUR-USERNAME.github.io/the-moon-called-deen/`

## Privacy note
GitHub Pages is public. Anyone with the URL may view the site and its photos. Share it privately, and only keep photos you are comfortable making public.
